# Stadiums of Italy

Interactive web map of Italian football stadiums built with Django, Leaflet and PostgreSQL.

## Features

- Interactive stadium map
- Serie A / Serie B / Serie C filtering
- Stadium ownership classification
- Stadium development tracking
- Detailed stadium pages
- Team and city pages
- GeoJSON API endpoints

## Tech Stack

- Django
- PostgreSQL
- Leaflet.js
- Bootstrap 5
- Render deployment
